# まる珈琲の値段

PER・EBITDA・EV/EBITDA を、町の喫茶店を一軒買う話として最初から説明するスクロール解説ページです。

**公開ページ → https://takuya-ops.github.io/maru-coffee-valuation/**

**実装ノート（デモ付き）→ https://takuya-ops.github.io/maru-coffee-valuation/docs/**
スクロール連動アニメーションの作り方を、スライダーで動かせる7つの実験台つきで解説しています。

## 内容

架空の喫茶店「まる珈琲」を題材に、株式のバリュエーション指標を順を追って説明します。

| 章 | 内容 |
|---|---|
| 一 | 株を買う＝会社の一部を買うこと |
| 二 | まる珈琲の帳簿（株数・株価・純利益・時価総額） |
| 三 | PER — 元を取るのに何年かかるか |
| 四 | EBITDA — 減価償却を足し戻す理由 |
| 五 | EV — 借金を足し、現金を引いた本当の値段 |
| 六 | EV/EBITDA — 買収する人から見た年数 |
| 七 | 借金のない「かど珈琲」と並べる（結論） |
| 付 | 略語の正体 / 早見表 / 落とし穴 / 最初に覚える三つ |

## 作り

- **単一ファイル**。`index.html` に HTML・CSS・JavaScript をすべて含みます。ビルド不要、依存パッケージなし。
- **イラストはすべて手書きの SVG**。`feTurbulence` + `feDisplacementMap` で線を揺らして手描きの質感を出し、同じフィルタを強くかけたものを水彩の滲みとして使っています。CSS 図形は使っていません。
- **スクロール連動**。各セクションの進行度を CSS カスタムプロパティ `--p`（0→1）と `--c`（画面中心からのずれ）に流し込み、視差・3D の傾き・コインの積み上がり・棒グラフの伸びをすべてそこから導いています。JavaScript は `requestAnimationFrame` 1 か所だけで、`transform` と `opacity` しか触りません。
- **ライト / ダーク両対応**。全色をトークンで定義し、水彩の合成モードも `multiply` ↔ `screen` で切り替えます。
- **アクセシビリティ**。`prefers-reduced-motion` 指定時と JavaScript 無効時は、全要素が静止した完成状態で表示されます。各イラストには `role="img"` と説明文を付けています。

書体は Google Fonts から Shippori Mincho B1（見出し）、Zen Kaku Gothic New（本文）、Klee One（手描き注釈）、IBM Plex Mono（金額）。

## 注意

まる珈琲・かど珈琲は架空の店です。登場する数字はすべて指標の仕組みを説明するために作った例で、実在の企業の値ではありません。実際の銘柄を見るときは有価証券報告書や決算短信などの一次資料にあたってください。

投資勧誘を目的としたものではありません。
